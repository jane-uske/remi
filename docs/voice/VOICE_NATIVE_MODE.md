## 0. 一句话立场

**端到端语音模型（Moshi / CSM / Qwen-Omni 这类）只是 Remi 的「实时语音外壳」，不是
Remi 的「灵魂」。** 它负责听感与口感（turn-taking、打断、语气、口型节奏），
**不负责** Remi 是谁。Remi Brain 始终保留：identity / memory / role / tools /
preference / **final reply authority（最终发言权）**。

如果哪天把「她说什么、她是谁、她记得什么」交给一个语音大模型自己即兴，那就不再是
Remi，只是一个会说话的通用语音模型。这条线不能越。

## 1. 两层分工

```
┌──────────────────────────────────────────────────────────────┐
│  Voice Shell（实时语音外壳，可替换）                            │
│  - 听：连续音频 in、turn-end 检测、barge-in                     │
│  - 说：低延迟、有气口/停顿的语音 out、可被瞬间打断              │
│  - 候选：本地端到端语音模型 / 级联(STT+TTS+turn detector)       │
│  - 输出：候选「该说什么」的草稿 + 韵律/时机信号                  │
└───────────────┬───────────────────────────────▲───────────────┘
                │ 候选意图 / 草稿 / 时机           │ 最终文本 + 情绪 + 边界
                ▼                                 │
┌──────────────────────────────────────────────────────────────┐
│  Remi Brain（灵魂，不可替换，最终权威）                          │
│  - identity：她是谁、人格内核、关系阶段                          │
│  - memory：长期记忆、关系连续性、core memory                     │
│  - role / tools：能力只服务陪伴，受人格约束                      │
│  - preference：用户偏好、风格指令、边界（NSFW / 严肃场景）       │
│  - FINAL REPLY AUTHORITY：最终说什么由 Brain 拍板               │
└──────────────────────────────────────────────────────────────┘
```

关键约束：**Voice Shell 可以「提议」，但不能「拍板」。**
最终发言权（措辞、人格、记忆引用、边界）永远在 Remi Brain。

## 2. 三种可能的 Voice Shell 形态（都服从同一边界）

| 形态 | Shell 做什么 | Brain 做什么 | 取舍 |
|------|-------------|-------------|------|
| A. 级联（现状方向） | STT + turn detector + TTS | 全部内容与人格 | 控制力最强，最像 Remi；延迟靠工程压 |
| B. 端到端「听」+ Brain「想说」+ TTS「说」 | 语音模型只做实时听感/时机/草稿，TTS 仍独立 | Brain 改写草稿为最终回复 | 听感升级，灵魂仍归 Brain |
| C. 全端到端语音对语音 | 语音模型直接听→说 | 仅做事后约束/纠偏（弱） | 听感最好，但**最容易丢失灵魂**，需要最强的 Brain 仲裁，默认不走 |

**默认路线是 A→B**：先用可插拔 turn detector / TTS provider（见 PLAN 的
TurnDetectorProvider / TTSProvider）把听感与口感做扎实；只有在 Brain 仲裁层足够强、
能保证「最终发言权」时，才评估 C，且 C 永远是「外壳」，不是「替代」。

---

## 3. 不可协商的红线

1. **最终发言权在 Brain**：任何端到端模型的语音输出，在涉及身份、记忆、关系、边界、
   人格时，必须能被 Brain 改写或否决。
2. **记忆/身份不下放**：Voice Shell 不持有长期记忆、不定义 Remi 是谁。
3. **可回退**：端到端模式必须能退回级联（legacy）路径，不删 fallback。
4. **边界继承**：严肃场景承接、NSFW 开关、安全红线由 Brain 统一裁决，Shell 不自行决定。
5. **她不变**：换 Shell 不能让用户感觉「换了一个人」。这是产品底线（见
   `docs/ops/CURRENT_FOCUS.md`：核心价值是「还是她」）。

## 4. 与阶段 1 的关系

阶段 1（TurnDetectorProvider / SpeechRuntime shadow / TTSProvider 形式化）正是
为「可替换的 Voice Shell」打地基：把听感/口感/时机收成可插拔接口，同时让 Brain
保持唯一的内容权威。**本文描述的端到端模式是这条路的远端可选项，不是现在要做的事。**
