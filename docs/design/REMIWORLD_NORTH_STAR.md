# REMIWORLD_NORTH_STAR.md — Remi 终局：LLM 驱动的虚拟世界伴侣

## 这份文档的用途

- 固化**终局方向**（世界线北极星），供接手世界线的 agent 启动时阅读
- 当前优先级永远以 [CURRENT_FOCUS.md](../ops/CURRENT_FOCUS.md) 为准；本文档只回答三件事：
  **终局是什么、按什么顺序逼近、哪些约束不许破**

## 终局愿景

Remi 不是普通聊天机器人，也不是单纯会动的 3D 皮套，而是一个
**有身体、有房间、有日常、有记忆、有情绪、有自主行为、能和用户在虚拟世界中自然相处**的 AI companion。

终局形态：

- 她不是等用户输入才存在。她一直生活在自己的世界里：看书、发呆、休息、听音乐、看窗外
- 用户进入她的空间时，她自然抬头、转身、打招呼
- 用户和她说话时，她停下正在做的事，用表情、口型、动作、语气和记忆共同回应
- 用户离开再回来，世界和她都记得发生过什么

这和主线的"想回来见她"是同一句话的两种说法：聊天框时代靠语气和记忆成立，
**"见"的终局形态是走进她的世界。**

## 与当前主线（W-PRES-01~04）的关系

**不存在两个北极星：**

- **世界是"在场感"主线的终局载体。** W-PRES-03（在场感统一）收口的语音/口型/表情/turn state，就是世界 Phase 1 的直接输入
- **W-PRES-01/02（人格稳定/严肃承接）是大脑侧修复，世界自动受益**；世界线不重复做、不抢大脑侧资源
- **Memory V2 读路径以世界为真实消费方**："她结合记忆回应"是读路径最自然的验证场，世界事件是温层 episode 的新鲜样本来源
- 世界线推进不改变 CURRENT_FOCUS 的执行顺序；冲突时以 CURRENT_FOCUS 为准

## 硬约束（破坏任何一条都算走偏）

1. **基于 RemiWorld v0.1 演进，禁止重做基建。**
   现有：`web/src/lib/world/`（engine/worldMap/mesher/textures/remiActor/script/memories）+ `/world` 路由。
   对话接缝在 `script.ts` 的 `ScriptUi.openDialogue`。
2. **同一个 Remi。** 世界是现有大脑/记忆/人格的**另一个客户端**：同一 Clerk 身份、
   同一 memory store、同一 persona。禁止长出记忆割裂的"世界版 Remi"。
3. **自主行为分层。** 日常行为 = 本地确定性调度器（零 token、可预测、可测试）；
   LLM 只介入对话、情绪表达和低频"导演级"决策。**禁止用 LLM 轮询驱动发呆。**
4. **持续存在走低档。** 世界状态服务端持久化 + 进入时按流逝时间推演她的日常；
   不做常驻服务端模拟（留升级口，不提前付钱）。
5. **内容层永不阻塞平台。** 第 6 方向（小游戏/做饭/故事接龙）是 Phase 4+，
   任何平台阶段不得以内容未完成为由延期。
6. **fast path 规则继续适用。** 世界事件进大脑走异步上下文注入，
   不在对话 fast path 里加阻塞性工作（同 CLAUDE.md 代码规则）。
7. **自主决策边界。** 技术选型/代码结构/迭代切分不必请示；
   以下四类**必须停下来问用户**：资产采购、付费服务接入、对外发布、删除数据。

## 活人感验收基准（每个阶段交付都要过）

| 基准 | 做法 | 通过标准 |
|---|---|---|
| 隔天回来 | 关闭一天后回来 | 世界状态保留；她的问候自然引用上次发生的事 |
| 打断恢复 | 对话结束后继续观察她 | 回到（或自然切换）之前的行为，不傻站 |
| 十分钟观察 | 不输入，只看 10 分钟 | 行为有节奏变化，无明显循环/鬼畜/穿模 |
| 记忆回指 | 随机问一件几天前说过的事 | 能接住且表达自然，不是检索式复读 |

### Phase 2 — 时间与日常

她的作息表（晨/昏/夜不同行为与灯光）、离线时间推演（"你不在的时候我…"）、
天气、主动开场白（复用 `proactive_planner` 的关系阶段/退避/冷却门控，不另造轮子）。

### Phase 3 — 空间互动

位置触发语境（窗边聊天 vs 花园聊天的上下文不同）、一起看东西（看日落/看记忆墙）、
物品交互扩展、她的行走与跟随。

### Phase 4 — 内容层

故事接龙、小游戏、一起做饭等陪伴式活动。骑在平台上，不反向定义平台。

## 终局也不做（非目标）

- 多人世界 / 社交玩法
- UGC / 开放世界尺度地图
- 通用助手工具面（工具只服务陪伴，同 CLAUDE.md）
- 用世界玩法堆砌替代关系质量——世界服务于"想回来见她"，不是反过来
